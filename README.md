## 📖 About The Project

**FNAFID** is my most ambitious and longest-running project, developed solo from May 2024 to May 2025. While it pays homage to the original FNAF franchise, it expands heavily on the formula by introducing dynamic storytelling, escalating environmental mechanics, and immersive visual engineering. 

It is a complete, fully playable experience built entirely in **Unity**, driven by 30 to 40 custom **C# scripts**, and polished with a heavy emphasis on atmospheric rendering.

### 🌟 Core Game Features
*   **Full Campaign & Custom Night:** Play through 5 intense, story-driven nights, culminating in a highly customizable 6th Night.
*   **Epic Boss Fight:** A unique addition to the genre—a multi-stage boss encounter featuring 3 distinct phases.
*   **Progressive Star System:** Track your achievements and game completion natively.
*   **Dynamic Main Menu:** The game remembers your progress, altering the visual state and atmosphere of the main menu as you survive each night.
*   **Behind-The-Scenes Credits:** An interactive credits sequence featuring a massive, synchronized collage of ~45 simultaneous video recordings from the game's year-long development phase.

## ⚙️ Gameplay & Nightly Progression

FNAFID doesn't just repeat the same loop; it evolves. Each night introduces new challenges and shifts the paradigm of survival.

*   **Narrative Integration:** The story unfolds directly through in-game dialogues and scripted events that occur exclusively at specific timeline triggers during the nights.
*   **Escalating Mechanics:** Players must constantly adapt. Mechanics evolve from simply watching cameras to physically interacting with the environment—walking to doors, peaking down dark corridors, and hiding under the bed.
*   **Dynamic Enemy Roster:** New animatronics and threats are introduced sequentially, each requiring a different counter-strategy.
*   **Final Hour Hardmode:** Surviving until the end isn't easy. The final hour of certain nights triggers "Hardmode," aggressively changing the visual atmosphere and drastically amplifying the animatronic AI logic.

## 🛠️ Technical Showcase & Development

This project was a massive undertaking in both programming and technical artistry. 

*   **Custom Animation Workflow:** While the base 3D models were sourced from the community, **100% of the character animations were created entirely from scratch by me in Blender**. 
*   **Object-Oriented C# Architecture:** The entire game logic, AI state machines, event triggers, and UI interactions are handled by a custom-written codebase (~40 scripts managed in Visual Studio).
*   **Visual Fidelity & Immersion:** Extensive use of Unity's **Post-Processing Stack** and **Cinemachine**. Lighting, color grading, depth of field, and camera shake were heavily manipulated to create a claustrophobic, terrifying, and deeply immersive atmosphere.

## 📦 Repository Structure & Game Builds

Due to GitHub's file size limitations for raw assets and compiled binaries, **this repository serves strictly as a codebase showcase.**

* 📄 **This Repository:** Contains 100% of the game's custom C# scripts, architecture, and project configuration files. Heavy 3D models, textures, and audio assets have been excluded via `.gitignore` to keep the code lightweight and scannable.
* 🎮 **Playable Game Build:** The full, pre-compiled game executable (with all graphics, animations, and sound effects bundled) is hosted separately.
